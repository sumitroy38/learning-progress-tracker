# Documentation

Welcome. This folder explains the Learning Progress Tracker in plain English. You do not need to know the technology to start. Every new word is explained where it first appears, and there is a [glossary](GLOSSARY.md) for quick lookups.

The live site is at https://learning-progress-tracker-q7rt.onrender.com and the code is at https://github.com/sumitroy38/learning-progress-tracker.

## How these docs are written

* Short sentences and everyday words.
* Each technical word is explained the first time it appears.
* Examples use made up names and data only.
* Commands are shown in boxes, so you can copy them exactly.
* No secrets are written here. Passwords and keys never belong in documents or in Git.
